# Content Lessons

Append-only for new lessons, newest first; existing entries may be sharpened
in place, never removed. Read at draft time alongside `voice-tone.md` —
lessons are constraints, same category as the voice ceilings. Written only from
Nick's hand-off feedback, never auto-derived from slopcheck output. Before
appending, check this file and `voice-tone.md`: if the new lesson restates an
existing entry or prohibition, sharpen the existing entry in place instead of
duplicating it.

Entry format:

```markdown
## YYYY-MM-DD — <post slug or working title>
- **Lesson:** <one sentence, imperative, checkable against a future draft>
- **Evidence:** <what Nick said or changed, quoted or paraphrased>
```
