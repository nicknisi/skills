# Idea Vault

Unpicked post ideas from idea-sourcing runs (SKILL.md, entry point 2). Read
this file before every sourcing run and re-surface still-relevant `open`
entries before scanning for new ones. `dead` entries are never re-surfaced;
Nick sets them. Mark an entry `drafted` when a draft exists.

Entry format, one line each, newest first:

```markdown
- YYYY-MM-DD · <one-line pitch> · evidence: <commits / log excerpts / links> · status: open|drafted|dead
```
